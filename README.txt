PERSONAL RESUME & BIO-DATA WEBSITE — CSS FIXED
==============================================

This corrected package has CSS in TWO places:
1. Embedded inside each HTML page (so styling works even if style.css is
   accidentally moved or the browser cannot find it).
2. In the separate style.css file (kept for the assignment source files).

HOW TO OPEN
-----------
1. Download this ZIP and choose Extract All.
2. Open the extracted folder.
3. Double-click index.html (NOT style.css).
4. Use the Home / Resume / Bio-data navigation links.

All six files are together in this folder. You may open index.html even if
style.css is accidentally missing because each HTML page has a CSS copy
embedded in its head section. For GitHub Pages, upload all six files to the
root of the repository.

PERSONALISE BEFORE SUBMISSION
-----------------------------
Replace square-bracket placeholders in index.html, resume.html and
biodata.html, including name, initials (YN), college, contact, education,
project, skills and hobbies. Use only true details.

HOST ON GITHUB PAGES
--------------------
1. Create a public repository on https://github.com
2. Upload all six files into the repository root.
3. Open Settings -> Pages.
4. Select Deploy from a branch, branch main, folder /(root), then Save.
5. Open the URL displayed by GitHub Pages after publishing.

TROUBLESHOOTING
---------------
- Extract the ZIP before opening files.
- Open index.html in Chrome/Edge, not style.css.
- Check the filename is index.html (not index.html.txt).
- If you use VS Code, open the extracted folder and run index.html with
  Live Server.
